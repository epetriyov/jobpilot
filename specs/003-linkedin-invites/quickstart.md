# Quickstart: проверка этапа 3 руками

## Предусловия

В `.env`: `LINKEDIN_COMPANIES=Яндекс;Авито;Ozon;Т-Банк;Сбер` (ваш список; можно начать с 2–3).

## 1. Гейты и миграция

```bash
make lint && make test && make migrate   # 0004_stage3
docker compose up -d --build
```

## 2. Пакет заготовок

Telegram: `/invites` → ≤20 карточек: роль+компания, ссылка people-search, текст ≤300 знаков, кнопка «📤 Отправил». Ссылка открывает поиск людей нужной роли в компании (проверьте 2–3, включая кириллицу).

## 3. Статусы

«📤 Отправил» → карточка обновляется, кнопка «✅ Принял»; «✅ Принял» → финал. Повторные нажатия — вежливый отказ. `/invites_status` — воронка.

## 4. Дедуп и напоминание

Повторный `/invites` → дубликатов нет; блок «неотправленные: N» при наличии proposed старше 3 дней (для проверки можно `INVITES_REMIND_DAYS=0`).

## 5. Анти-ToS гарантия

`make test` включает grep-тест [N-U3]: в кодовой базе нет HTTP-обращений к linkedin.com.

## 6. Eval (после подключения реального LLM)

```bash
make eval CONTEXT=invite_rubric   # pass ≥0.9
```

## 7. 🖐 Закрытие этапа

Проверить 5 заготовок глазами → вручную отправить первую партию → подтвердить.
