# Contract: переменные окружения (Этап 5)

| Переменная | Дефолт | Назначение |
|---|---|---|
| `SITES_ACTIVE` | `` (пусто) | сайты-источники в **основном** потоке дайджеста, через `;` (только одобренные). Тяжёлые (Playwright) не включать до апгрейда железа |
| `SITES_CANARY` | `` (пусто) | сайты в режиме канарейки — вакансии в секцию «На проверку» до `/approve_scraper` |
| `SITES_HEAVY` | `ozon` | справочный список «тяжёлых» (Playwright) сайтов — гейтятся апгрейдом железа (INFRA.md §4.2); при попытке активации без Chromium — понятная ошибка |
| `SITES_RATE_LIMIT_SEC` | `1` | минимальная пауза между запросами к одному порталу (≥1 s, [S-C10]) |
| `SITES_TIMEOUT_SEC` | `20` | таймаут HTTP/браузерного запроса |
| `SITES_USER_AGENT` | `JobPilot/1.0 (+owner-contact)` | честный `User-Agent` с контактом владельца ([S-C10]) |
| `SITES_EM_KEYWORDS` | `engineering manager;руководитель разработки;head of engineering;team lead;тимлид` | ключи EM/лид-ролей для адаптерного фильтра (FR-004); правит владелец |
| `SITES_ROBOTS_RESPECT` | `true` | уважать robots.txt целевого раздела (запрет → сайт не скрейпится) |

Допустимые имена сайтов: `yandex`, `vk`, `avito`, `tbank`, `ozon`, `alfa`, `sber` — валидируются
на старте; неизвестное имя в любом списке → понятная ошибка конфига ([F-U1]).

**Секретов у этапа нет** — карьерные порталы публичны, кредов/токенов не существует по
построению. Обход капчи/анти-бота не конфигурируется (его нет — S5, constitution IV).

`/approve_scraper <site>` — не env, а команда владельца в боте; факт одобрения персистится в
таблице `scraper_approval` (data-model.md).
