# Contract: переменные окружения (Этап 4)

Дополнение к contracts/env.md предыдущих этапов; ведутся в локальном `.env` владельца.

> Источник GetMatch — публичный JSON `GET /api/offers` через **httpx** (без логина, без браузера). Секретов у источника **нет**. Источник **выключен по умолчанию** — включается осознанно после canary (constitution VI) и решения по robots/ToS (research §2).

## Режим и активация

| Переменная | Дефолт | Назначение |
|---|---|---|
| `SOURCES` | `email` | активные адаптеры источников через запятую; добавить `getmatch` для включения (например `email,getmatch`) |
| `GETMATCH_MODE` | `fake` | `fake` — стаб-источник из golden (сеть не трогается); `real` — httpx к `/api/offers`; `auto` — real при `getmatch` в `SOURCES`, иначе fake |

> Флаг источника ведётся единообразно с HH (`HH_SOURCES`): либо через общий `SOURCES`, либо через `GETMATCH_MODE` — конкретная схема согласуется на T401 с существующей композицией пайплайна. Пока владелец не включил — источник неактивен.

## Доступ (публичный, без секретов)

| Переменная | Дефолт | Назначение |
|---|---|---|
| `GETMATCH_API_URL` | `https://getmatch.ru/api/offers` | публичный JSON-эндпоинт списка offers |
| `GETMATCH_PAGE_LIMIT` | `20` | `limit` на страницу; пагинация `offset += limit` до `meta.total` |

## Вежливый доступ (дефолты)

| Переменная | Дефолт | Назначение |
|---|---|---|
| `GETMATCH_USER_AGENT` | `JobPilot/0.1 (personal-agent; owner-contact)` | честный User-Agent (PLAN §7); идентифицирует персонального агента владельца |
| `GETMATCH_REQUEST_PAUSE_SEC` | `1.0` | пауза между страницами (≥1 c, 1 rps; аналог [S-C10]) |
| `GETMATCH_TIMEOUT_SEC` | `20` | таймаут httpx-запроса; при исчерпании ретраев → `SourceFetchFailed` (S4) |

## Примечания

- **Секретов нет**: публичный фид не требует токенов/куки/логина — в `Settings.secret_values()` добавлять нечего.
- **robots.txt `Disallow: /api/`** — не переменная, а ToS-ограничение: включение источника только по явному owner-approval (research §2); обход блоков/капчи не проектируется (S5, constitution IV).
- **Никакого Playwright/Chromium** — переменных браузер-профиля (в отличие от HH-web хвоста) у GetMatch нет; источник исполняется на текущем железе (`docs/INFRA.md`).
- Персональный фид `/api/vacancies` (требует логина) — вне scope этапа; если будет подключён отдельной спекой, тогда появятся секреты сессии.
